## 本轮实现

- 首页左栏保留真实本地稿件；进入稿件后改为本稿页面和当前页图层树，跨稿继续用顶部标签。支持新增页面、切页、层级展开 / 收起、树与画布双向选中；空页无旧行、旧属性或悬浮轮廓。
- Kodma 宿主的 `canvas/selection` 为 `#6738EF`，只绘制覆盖层，保留对象描边和文件内容。默认 FigCraft 与 S001 入口继续使用自己的外观。
- 原生控件仍是同一 FigApp / Session 的只读投影，页面和选区提交原 `page.select` / `select.set`；回调携带稿件 UID，图层回调另校验当前页及节点归属，删除 / 关闭 / 切稿后的旧行不能重定向。
- 图层树只为可见行创建 AppKit 控件。投影最多读取1024页、当前页10000个节点及128层深度，展开状态保留上限65536项并移除已删除分支，缩进视觉上限8层，避免畸形文件导致无界分配或递归；不删除原文档或限制原画布 / MCP 中的数据。展开状态属于宿主展示状态。
- 先设置父容器尺寸，再布局子滚动区，防止新启动时右栏顶部位置被零尺寸父容器错误裁到末尾。当前页重复点击保持原选区和视口；真正切页或新增页时清除原引擎悬浮状态，避免旧页轮廓残留。

原生检查器使用自己的标准 backing store 保留静态标题和字段底板，首页往返后已实际复查；原画布 Metal layer 不变。

本轮没有第二套文档、命令或撤销历史，没有新增依赖、资产文件、unsafe 或 CI 工作流修改。

## 运行与亲验

```sh
./script/accept_s002_i5.sh
```

已构建同一版本可加 `--no-build`。每次使用独立配置和新文件，进入首页；脚本只准备夹具，不自动宣称验收通过。清单位于 `dist/s002-i5/latest.json`，MCP 默认仍可使用对应的 `dist/s002-i4/latest.json`。

验收“退出再重开”时使用 `./script/accept_s002_i5.sh --resume`，保留这次配置、最近列表和文件，从首页重新打开A/B。不要重新运行生成入口来代替持久化验收：默认入口及`--no-build`都会生成一轮新夹具，`--resume`才只重启现有测试。

1. 首页打开 A/B，进入 A：左栏只显示 A 的「属性与层级」「空白页」，不再列其他稿件；顶部标签仍可切 B。
2. 展开「层级验收」，点击「子图层」：画布与右栏指向同一真实文字；再从画布点蓝色矩形，树中高亮随之更新。
3. 保持蓝色矩形选中，重复点击当前页：选区和视口不变。切「空白页」后树和右栏清空，画布不残留原矩形的紫色悬浮框；返回后从树重新选中矩形。
4. 选中任意普通对象，检查紫色选框；修改 W180、撤销恢复150，检查原描边未改变。字段输入999后直接切页或切 B，不确认的草稿不写入其他目标。
5. 先在 A 选主矩形，再切 B，运行 `ruby script/s002_agent_edit.rb 17982 A`：B 保持原样，返回 A 后原选区和右栏显示珊瑚色。拖动 A 后撤销两次，分别撤销手势和 MCP 修改。
6. 保存、关闭并从首页重开 A/B，检查原数据、页面、层级和复杂样式；继续沿用[完整16步 case](acceptance.md)。系统中文按[I4 第7步](i4-properties.md)由用户验收。

`script/verify_s002_i5.rb PORT PID` 是开发侧协议 / attached MCP 与短程资源探测，需要先打开生成的 A/B。它检查前台 / 后台 / 首页定向修改、只读版本拒绝写入、保存重开和30次循环，不替代真实鼠标、窗口缩放或中文输入法。可用 `KODMA_S002_MANIFEST` 指定另一份合成清单，`KODMA_CANVAS_CLI` 指定匹配的隔离 CLI。
