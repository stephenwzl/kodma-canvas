# S003 I2：整窗 UI 运行验收

日期：2026-11-17。状态：用户已确认 UI 可以，视觉验收通过，后续进入 I3。

## 设计与实现

沿用 [I1 live 来源与范围](i1-design-and-storage.md)。首页保留字标、两行标题和原有合法插画，移除 Agent 输入与模板；按可用宽度缩放标题和插画并居中排列。首页搜索变为原生输入，列表项提供菜单，底部明确“打开稿件…”。编辑态保留标签、页面 / 图层树、工具条、选区和设计属性，隐藏未接通的 Agent / 分享 / 账户和设置入口。

菜单使用原生下拉控件，按捕获的文件路径操作，提供重命名、另存为和外部记录移除。重命名是原生输入 / 确认卡片；空白名显示必要错误并禁用保存。移除确认清楚说明磁盘文件保留，取消不更改目标。原生字段接入既有输入上下文交接与编辑菜单，避免画布处理字段快捷键。Enter / Escape 配置原生按钮 key equivalent，并沿用既有 IME 感知按键轮询；150 ms Escape 已观察取消，极短合成按键仍有漏接边界，完整快捷键与中文在功能保障阶段继续验证。

打开文档的列表名称取自实际 doc.name，路径不改；关闭文件的名称索引仍由 I3 / I4 完成。最近文件上限仍为 20；本轮长列表是 20 个合成外部文件，不代表全部受管稿件和 >20 持久化已通过。

## 状态预览边界

废纸篓和保存失败状态使用真实原生窗口控件，通过启动脚本显式选择的合成预览呈现：确认操作禁用，只能取消，不会实际删除或伪报保存成功。正式产品的受管稿件 / 保存失败重试由 I3 / I4 接入。预览未混称为真实废纸篓或写入故障测试。

## 复现入口

按仓库现有脚本启动原生工作区，使用隔离配置和合成稿，不打开个人文件：

```sh
KODMA_CANVAS_CONFIG_DIR=/tmp/kodma-s003-i2-review ./script/build_and_run.sh --workspace --verify --control 17994
ruby script/prepare_s003_i2.rb 17994
```

状态预览分别使用同一启动脚本的 --ui-state=trash 或 --ui-state=save-error（可加 --no-build）；正常启动不带该参数。预览不会执行文件写入或删除。复杂稿可复用 script/prepare_s002_i4.rb 生成的独立合成 A/B，须在空隔离宿主运行。
