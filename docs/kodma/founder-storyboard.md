# Kodma 预热视频 · 创业者篇

**定稿日期：2026-11-14。总长：27 秒。画幅：9:16。** 一位创业者用一张照片说明想法，在 Kodma 里生成一套界面、选中一页用一句话改稿，随后把设计稿交给开发 Agent。手机上启动的 App 把片头那颗草莓变成英语单词贴纸。

配套画板在协作文件 `kodma` 的「Kodma · 创业者篇｜27 秒分镜」页。文件入口见[产品设计与工作进度](README.md)。拍照变单词贴纸的创意参考 [CapWords 创始人访谈](https://developer.apple.com/cn/articles/capwords/)；片中使用原创演示稿。当前画板是低保真分镜，表内动作描述的是成片效果。

## 分镜与剪辑

全片用界面文字交代指令，声音由快门、发送、选中、纸张等动作构成。Kodma 镜头使用同一套横向桌面工作区，在竖屏视频中通过缩放、平移取景。手机竖屏仅用于拍摄现场、画布里的 App 设计稿和结尾的真机演示。

| 时间（秒） | 画面与运镜 | 操作、文字与声音 |
| --- | --- | --- |
| 0.0–1.5 | 一只手握住手机，对准背景中的草莓。手、手机、取景框和背景中的草莓同时入画。 | 拇指按快门。一声快门落下，整幅画面定格。 |
| 1.5–2.4 | 从定格画面连续拉远，先露出图片的四条边。手和手机都留在图片里。 | 保留快门尾音。图片边缘出现时稍稍减速。 |
| 2.4–3.5 | 延续同一镜头，露出 Kodma 左侧导航、中央画布和右侧 Agent 面板。刚才的画面成为画布上的一张参考图。 | 轻音乐进入。 |
| 3.5–7.0 | 镜头移向右栏，左侧仍能看见参考图。 | 输入「我想做一个拍照把物体变成贴纸，学习英语单词的 App」。按语意分段出现，整句停留半秒，发送。 |

| 10.8–12.0 | 镜头跟随鼠标移向「英语词本」。 | 单击选中画板，出现蓝色选框。 |

| 14.8–16.8 | Agent 短暂加载，镜头回到原选区。词本页在原位弹起，切换为新版，再回落。 | 贴纸旁出现发音入口，其余稿件保持原位。用一次轻音标记更新完成。 |
| 16.8–18.3 | 切到第三方开发 Agent 的桌面对话输入框，构图参考 Codex。先让观众看清输入框顶部的附件。 | 附件呈现 Kodma 字标、刚才那套稿件的缩略图及稿名「草莓词本」。 |
| 18.3–20.4 | 附件留在输入框顶部，焦点落在下方光标。 | 输入「就按这个开发」，发送。发送声后直接切真机。 |
| 20.4–22.0 | 手机主屏特写。手指点开 App，切入真实拍摄界面。 | 保留轻点声，让启动后的取景框清晰入画。 |
| 22.0–23.7 | 手机再次对准片头那颗草莓。尽量复用同一拍摄位置、持机方向和背景。 | 对焦、按快门；快门声呼应第 1 秒。 |
| 23.7–25.5 | 草莓轮廓从照片背景中分离，抠出的主体带上贴纸白边和英文 strawberry，落成单词贴纸。 | 抠像完成时配轻微揭纸声，结果停留至能读清单词。 |
| 25.5–27.0 | 淡入暖白品牌尾板，原有小写 kodma 字标居中，下方显示「今天，想把什么画出来？」。 | 最后一个音落在字标出现时，定格到片尾。 |

## 制作素材

- **桌面工作区与 UX 稿**：同一份横屏 Kodma 稿件，保留参考图、右侧对话及固定的词本位置。准备一套高保真手机界面，以及同一词本页修改前、带发音入口的修改后两种状态。
- **开发 Agent 镜头**：准备带 Kodma 稿件附件的桌面输入框、可辨认的缩略图和一次发送动作。
- **真机与转场**：配对拍摄片头和片尾的草莓镜头，另录 App 启动、取景和贴纸生成。低保真画板中的手机画面用作机位参考。
- **品牌与声音**：使用 Kodma 现有 Agent 图标、字标和首页原句。首尾共用同一快门音色。
