## 测试准备

准备隔离配置与合成稿，两个测试账户 U / V，以及两个真正独立的浏览器环境 A / B（独立 profile 或不同浏览器，不能只是共用同一 localStorage 的两个标签）。首版跨设备 case 最终在两台设备执行；开发阶段独立环境结果仅标为阶段证据，不冒充物理跨设备验收。

合成稿含普通矩形、中文文字、富文本、渐变、图片、父子层级及空页；准备同名稿、损坏文件、超过名额稿件、网络 / 存储故障。I1 固定输入值、大小边界、预期内容与持久 ID，开发时提供可复现生成 / 启动 / 清理方式。不得使用真实私人稿件或把凭据写入证据。

## 用户亲验主线

1. 打开 Cloudflare 测试地址，先对照首页和编辑窗口 UI。
2. 在设备 A 登录 U → 新建“阅读记录” → 修改矩形和中文文字 → 等待云端保存成功。
3. 在设备 B 登录 U → 从列表打开同一稿件 → 核对内容 → 改名并保存；设备 A 刷新重开核对。
4. 搜索、下载副本、导入副本、软删除与恢复；登录 V 确认看不到 U 的稿件。
5. 断网修改并恢复，再检查两端旧基准增量的重连 / 收敛与不可重放分支，确认稿件保留且反馈明确。

完成视觉、功能与部署验收后由用户确认是否关闭 S004。当前仅有规格，尚无可验收 Cloudflare 地址或测试账户；不能提前将任一 case 标为通过。
