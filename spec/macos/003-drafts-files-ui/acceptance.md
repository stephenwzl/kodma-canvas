## 测试准备与交付要求

开发时提供一条可复制的启动命令及合成稿生成入口，沿用项目构建启动脚本；已有 script/build_and_run.sh、script/verify_s003_i3.rb 和 script/verify_s003_i4.rb。使用隔离配置与测试目录，不修改用户真实文件。重新启动测试必须复用同一轮配置 / 文件，不用重新生成夹具冒充恢复成功。

准备：应用内稿件 A / B（不同颜色、尺寸、文字；含渐变、富文本、父子图层与空页）；同名稿 C；超过 20 份应用内稿件；外部 E；损坏文件、被移走文件、受控不可写目录。记录每份稿件的持久标识、路径与期望内容，不用列表行号当身份。截图、文件回读、命令日志的凭据及个人信息不得入库。

## 稿件与文件闭环

### C03 · 新建后能再找到（AC03）

1. 空首页新建两份稿件，检查每份真实可编辑且身份独立，默认名称不覆盖旧稿。
2. A 命名为“阅读记录”，创建一个合成矩形；B 命名为“流程草稿”，写入不同文字。
3. 关闭标签、回首页分别再开；正常退出，等待进程结束，再用同一配置重启。
4. 从列表打开 A / B，核对名称、图层和文件内容；不需要首次选择保存目录。创建成功必须有初始文件和有效列表记录。

### C04 · 名称、取消与同名（AC04）

1. 对 A 用中文、英文、长名重命名，分别 Enter 确认和 Escape 取消；测试纯空格拒绝。
2. 将 C 命名为与 A 相同，分别打开，确认不会覆盖 / 合并 A。
3. 保存重启，核对列表、标签、文件内名称，持久标识不变；外部 E 改文档名后磁盘路径不自动改名。

### C05 · 保存、关闭与退出（AC05）

1. 修改 A 的几何与文字，观察真实保存状态和 I1 约定的自动保存触发；回首页再打开核对。
2. 保存后读文件，再正常退出重启，检查最后一次已确认修改；复杂填充 / 富文本 / 层级仍保留。
3. 在有待保存修改时关闭标签和退出：等待保存或处理可取消的确认；取消后仍可编辑，不静默丢修改。

### C06 · 外部打开、另存为与冲突（AC06）

1. 从系统选择器打开 E 两次，只复用同一文档；同名不同路径文件仍独立。取消选择器不新增空标签。
2. A 修改并保存，再另存为外部 E2。原 A 的已保存文件仍可找到；当前标签、路径和列表按 spec 规则更新。
3. 修改 E2，不应改变原 A。分别关闭 / 重开，核对两个文件和持久身份。
4. 取消另存为、目标不可写、目标已存在、外部文件被其他进程修改时，检查确认或冲突反馈；失败不得清 dirty、改错目标或损坏原文件。

### C07 · 完整列表与搜索（AC07）

1. 创建至少 25 份应用内稿件，退出重启后仍全可发现，不受最近 20 条限制。
2. 按中文 / 英文名搜索，检查匹配、无结果、清空恢复；搜索不改变磁盘内容或删除记录。
3. 列表刷新 / 排序后执行此前打开的菜单操作，验证仍针对原身份，不能命中移到该行的新稿件；同路径去重、同名不误合并。

### C08 · 移除记录与废纸篓（AC08）

1. 对外部 E 选择“从列表移除”：列表不再显示，磁盘 E 与内容仍存在，已打开稿件不丢修改；显式重新打开可再次登记。
2. 对应用内 A 选择“移到废纸篓”，先取消，检查原状态；再处理待保存修改并确认。
3. 成功后仅 A 从列表和标签消失，B 不受影响；在系统废纸篓中确认文件可恢复，恢复后通过打开文件核对内容。不要求应用自建回收站。
4. 模拟废纸篓 / 存储操作失败，检查 A 的文件、列表和标签均保留；不得直接永久删除兜底。

### C09 · 失效文件与旧记录（AC09）

1. 用隔离配置保留旧最近记录，再启用新稿件管理；不自动搬迁 / 删除外部文件，重复启动不重复登记。
2. 分别打开缺失、损坏与无读取权限文件，检查实际错误和移除失效记录入口。
3. 失败不产生空白替代稿、幽灵标签或污染 B；恢复文件后可重新打开。

### C10 · 写入失败与重试（AC03 / AC05）

1. 在隔离目录通过可恢复的故障注入使新建初始落盘失败，记录实际错误与内存内容；首页不得显示假成功记录。
2. 对已打开 A 模拟后续写入失败，检查 dirty 仍在、修改可编辑、关闭可取消。
3. 恢复可写状态后重试，确认只创建 / 保存一份目标稿；正常重启回读最终内容，失败前的有效文件未被截断。
