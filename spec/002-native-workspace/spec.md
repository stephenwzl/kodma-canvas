# S002：macOS 原生工作区最小闭环

更新日期：2026-11-16。修订：v1.1。状态：I1–I2 开发与本轮验收完成，I3–I5 尚未开始，S002 未关闭。前置阶段 [S001](../001-canvas-editor/spec.md)已由用户验收通过；本轮文档基线为 `c7dde630`。

## 目标

让用户从 Kodma 原生首页打开本地稿件，通过原生标签切换稿件，在固定的「设计」右栏读取和修改真实选区属性，并完成撤销、保存、重新打开与 attached MCP 修改的连续操作。

沿用 S001 的同窗承载方式和完整 FigCraft 运行时。已有多稿件、文件操作、选区、撤销、工具、渲染及 MCP 是本阶段的接入基础；开发重点是原生界面与原状态、命令、焦点和画布区域的正确连接。

产品布局及交互依据[设计记录](../../docs/kodma/README.md)，状态归属依据[工作区架构](../../docs/kodma/workspace-architecture.md)。本次已通过 live 稿件逐项核对，来源节点、布局及未覆盖项见[高保真对照](design-reference.md)。S002 是功能接入子集，不是四页高保真的完整还原。人工流程见[验收 case](acceptance.md)，实施结果逐轮写入[进度](progress.md)。

## 开发范围

| 部分 | 本阶段交付 |
| --- | --- |
| 原生入口与布局 | 提供独立的 Kodma 工作区启动入口，并记录实际启动命令；保留默认 FigCraft、S001 仅画布及验证宿主入口。顶部稿件标签、左侧稿件列表、首页和固定右栏按已确认设计接入原生控件，工作区不出现 S001 的输入法下拉框、宽度滑块等测试控件 |
| 首页与本地列表 | 展示原有本地最近稿件信息，支持新建和系统文件选择器打开 `.figcraft`。列表使用实际文件信息；缺失文件、打开失败及取消选择器沿用既有错误与取消语义。新建进入真实可编辑文档 |
| 稿件标签与首页切换 | 首页与打开的稿件之间切换；标签显示真实名称、当前项及未保存状态。打开已打开的文件复用既有文档，关闭标签复用未保存确认。返回首页保留打开稿件，关闭最后一份稿件后回到首页 |
| 固定设计右栏 | 从当前文档的实际选区刷新名称、几何、不透明度、纯色填充及基础文字属性；支持范围见下表。没有选区、字段不适用或不可编辑时采用对应空态或禁用控件 |
| 保存与撤销 | 从原生工作区触发现有保存 / 另存为流程；取消不丢修改。一次属性提交或一次画布手势保持原有撤销事务。保存后的文件能退出应用并重新打开继续编辑 |
| 同一文档的 MCP | attached MCP 使用明确稿件目标读写同一运行时。修改前台稿件后画布与右栏同步；修改后台稿件不改变当前标签，不污染前台右栏 |
| 回归与交付 | 新增宿主适配处的回归，实机走通 A/B 双稿件 case；提供一键启动及可重复生成的合成稿件。核对默认入口、WASM、质量检查及适配差异 |

首页采用首页布局；设计右栏只在稿件工作区显示，返回首页时不显示上一稿件的属性。

### 高保真对照与交付边界

以 `e37912c2dd7d1294` 的「Kodma · 高保真 UI」与 Design System 为视觉来源，范围内布局按 1440 × 960 画板的左栏 242、顶部 84、右栏 408 逻辑尺寸接入；最小宽 1200 的实际容纳情况在 I1 验证。首页意图输入 / 三个快捷入口、原生页面导航、悬浮工具条、圆角 / 描边 / 效果，以及 Agent / 账户 / 分享界面尚未纳入当前最小闭环；逐项差异必须随交付列出，不用静态控件或模拟结果补齐。旋转、文字字段和多选状态是本阶段补充验证范围，其布局按既有组件规范落实并记录。

### 右栏的最小属性集

| 选区 | 可编辑范围 | 约束 |
| --- | --- | --- |
| 单个可编辑图层 | 名称，X / Y / W / H，旋转，不透明度 | 使用原引擎坐标、单位、约束与校验；自动布局等限制仍由引擎决定，控件按实际可编辑能力启用 |
| 单个只有一项纯色填充的图层 | 该项填充颜色 | 渐变、图片、变量绑定或多重填充保留原数据；本阶段不将复杂填充转换成纯色 |
| 单个文字图层 | 整层文字内容、字号 | 带富文本范围或混合样式时，仅开放引擎能够无歧义修改且保持其他样式的字段；其余显示已有值并禁用，不隐式扁平化样式 |
| 多选 | 共同的不透明度，以及所有目标都满足条件的单项纯色填充 | 混合值在控件内显示混合状态，只有明确提交某一字段才修改该字段；本阶段多选名称、几何和文字内容不开放编辑 |
| 无选区、只读或目标已失效 | 无写入 | 不沿用上一稿件的值；只读行为由原引擎最终校验，不能只依赖按钮禁用 |

数值、颜色等在 Enter、Tab 或同一稿件内结束字段编辑时提交；Escape 取消。文字内容在确认提交时形成一个可撤销修改，不为每个原生按键提交命令。切换稿件、返回首页、关闭目标稿件或改变选区时，取消尚未提交的属性草稿；已提交的修改留在原稿件。画布上的原有文字和工具手势继续遵循 FigCraft 现有规则。

### 后续阶段

本阶段只接本地稿件工作区与设计右栏。内置 Agent 对话、模型调用、任务持久化 / 重试 / 取消、账户、云端名额、付费和完整同步恢复另立规格。成员头像、聚焦、分享权限面板、外部 Agent 独立成员身份及双客户端完整协作矩阵随后接入；现有运行时中的协作继续工作，本阶段不重写这些能力。

导入格式扩展、完整原生属性检查器、渐变 / 图片 / 自动布局编辑面板、工作区标签布局持久化及多窗口产品化不在本阶段。保留原画布能力和稿件数据，不以隐藏或未接入原生入口为由删除逻辑。跨物理显示比例测试沿用用户决定，不作为 S002 的验收要求；当前屏幕上的窗口缩放、区域变化和界面缩放仍需验证。

## 技术与交互约束

1. 保留同一 `Session / FigApp / UiState`、帧循环、渲染、控制队列和后台调度。原生控件读取必要快照，提交原命令；不维护第二套可编辑文档、撤销栈或稿件列表真相。
2. 保留现有 NSWindow / WinitView 及其所有权，不把已验证同窗组合描述成 SwiftUI 拥有整个窗口。若具体控件需要安全桥接，在宿主层处理，不全局放松 unsafe 约束、不顺便升级 egui / eframe / winit。
3. 首页是展示状态，不是伪造文档。原生标签以运行时文档身份为键，当前项反映原运行时；按索引调用既有切稿命令时，提交前由身份重新解析索引，避免关闭标签导致索引漂移。
4. 原生属性草稿捕获目标文档身份、节点集合和编辑代次。切稿、换选区、关稿件或目标删除后失效；迟到事件不得回退到“当前文档”或同编号节点。字段原值被外部修改时，取消该字段旧草稿并刷新，不静默覆盖新值。
5. 文档变更、选区变化、切稿、撤销 / 重做、保存和 MCP 结果均驱动快照刷新；稳定界面不靠无条件全量重建控件。快照读取与命令提交在原运行时允许的线程和阶段执行，UI 适配不阻塞后台处理。
6. 顶部、左侧及右栏占用的区域纳入真实画布布局和命中坐标。扩展 S001 仅预留右侧区域的策略，不以原生控件遮挡仍接收输入的画布替代区域适配。首页不可见的画布不接收鼠标编辑，但继续处理后台命令。
7. 原生输入拥有键盘时，画布快捷键不执行；回到画布后恢复原快捷键。复用并扩展 S001 的原生编辑菜单、中文预编辑交接和退出前清理，覆盖多个属性字段及系统对话框。
8. 界面遵守既定布局和 token；控件表达用途，不增加二级说明、重复标题或口号。新增图标仅使用允许的原创 / 开源来源并按仓库要求归档。不得加入第三方产品资产。

## 验收标准

| 编号 | 场景 | 判据 |
| --- | --- | --- |
| AC01 | 启动产品工作区，对照已确认设计与默认入口 | 按[高保真对照](design-reference.md)检查范围内首页、标签、列表及固定右栏的尺寸、token、控件状态；附缺项与差异，不能标成完整还原；无上游外围 UI 与 S001 测试控件；默认 FigCraft 和 S001 入口行为保留 |
| AC02 | 首页新建、打开 A、取消打开、缺失文件、回到首页 | 操作真实文件和文档；取消 / 失败不产生幽灵标签或破坏当前编辑；首页显示当前本地记录，返回首页保留已打开稿件 |
| AC03 | 打开 A/B，反复切换，重复打开 A，调整窗口及界面缩放 | 每份稿件保留其选区、视口和撤销 / 重做；重复打开按原路径复用；画布、手柄与命中一致，原生栏区域不吞画布输入或被画布响应 |
| AC04 | 保存、另存为、取消保存、关闭脏稿件、关闭最后一份、退出重开 | 原确认及取消语义有效；保存失败不清 dirty，取消不丢修改；保存后重开内容保留，最后一份关闭回首页，无旧标签回调残留 |
| AC05 | 右栏单选 / 多选 / 无选区，改宽度、颜色、不透明度和文字 | 按最小属性集启用；一次提交可一次撤销，未改字段保留；混合值不自动写入所有对象，复杂填充和文字样式不被简化 |
| AC06 | 属性草稿未提交就切 B / 换选区 / 关 A；延迟事件在之后到达；目标被外部删除或修改 | 旧草稿和失效回调不写入 A 或 B，不凭相同 NodeId 命中另一稿件；冲突明确取消旧草稿并刷新；原生 UI 与命令路径都拒绝不可编辑目标 |
| AC07 | 多个原生字段与画布间切焦点，中文组词 / 取消 / 替换及原生编辑快捷键 | 无串字、丢字、重复提交或旧预编辑；候选框位置经实机观察；原生 Delete / Cmd+A/C/V/Z 不修改画布，回到画布后恢复；对话框取消后继续编辑 |
| AC08 | attached MCP 修改前台 A；在 B 可见或首页时定向修改 A；再返回 A | 仍为同一运行时；A 修改可回读并绘制，B 及其右栏不变；恢复 A 显示新值，外部修改与人工提交的撤销边界正确，无效目标 / 只读写入被拒绝 |
| AC09 | 隐藏 / 恢复窗口，重复进入首页和切稿；对照 S001 的启动、退出和短程资源指标 | 后台命令正常；无重复控件 / 事件或持续资源增长迹象；运行适用质量检查，区分新增回归、原有失败与未执行项；不把短程探测写成长程无泄漏保证 |
| AC10 | 审查本地适配差异，并在明确上游提交的隔离副本复测工作区核心流程 | 记录版本、应用差异 / 冲突、构建、首页→A/B→右栏→MCP→保存重开结果；不自动升级主分支或宣称未来自动兼容 |

具体验收步骤与输入数据见[人工 case](acceptance.md)。I1 已实现原生框架、只读快照和专用合成文件 / MCP 验证入口，见[实施说明](implementation.md)；完整 S002 A/B 夹具、可编辑原生字段与 AC 全量验收仍待后续迭代。
