1. 一条构建 / 启动产品工作区并生成测试稿的入口，建议为 `script/accept_s002.sh`；打印实际控制端口、A/B 文件位置及回归日志目录。使用独立验证配置，不读取私人稿件；每次生成新文件，不覆盖前次验收修改。
2. 两份可重复生成、保存后可重新打开的本地 `.figcraft` 稿件；生成内容来自原创合成命令，不加入外部产品资产。
3. 一个真实 attached MCP 修改脚本，建议为 `script/s002_agent_edit.rb`：从本次测试清单解析 A/B 的文件目标，明确指定目标稿件，读回结果；不能仅依赖当前标签或上次运行的文档 UID。
4. 固定环境、版本、截图及节点 / 文档状态回读记录；按设计对照逐项标注实现、差异和未交付项。在 1440 × 960 内容区与 1200 最小宽分别检查布局；节点尺寸使用逻辑单位，截图另记显示比例。原生控件与系统输入法需实机操作；机器注入输入和属性命令各自注明，不能互相替代。

脚本名称在实施时确认后写入进度。当前已提供 I1 专用验证和 I2 三份文件夹具 / 亲验入口；I3 已提供相同主矩形 NodeId 的真实 A/B，I4 已提供渐变和混合样式文字夹具，见[初值与清单](i4-properties.md)。I5 复用这些文件并补齐工程续验，S002现已由用户整体验收通过；工程证据与用户结论仍分别记录，不将I1子集结果扩写成全部机器测试通过。

### 合成稿件的预期初值

| 内容 | 稿件 A：S002 A | 稿件 B：S002 B |
| --- | --- | --- |
| 主矩形名称 | A · 蓝色 | B · 薄荷绿 |
| X / Y / W / H | 120 / 200 / 150 / 100 | 360 / 200 / 220 / 120 |
| 旋转 / 不透明度 | 0° / 100% | 0° / 60% |
| 单项纯色填充 | `#61B8F6` | `#99D9BD` |
| 普通文字 / 字号 | “你好，Kodma A” / 32 | “你好，Kodma B” / 24 |
| 补充对象 | 一项不透明度 50%、珊瑚纯色的辅助矩形；另有渐变或图片填充及带混合样式的文字，用于验证未接入属性不丢数据 | 一项用于验证切稿隔离的辅助矩形 |

生成器应让 A/B 的主矩形具有相同 NodeId，并在清单中分别记录所属文件。相同 NodeId 不表示同一个对象；这是检查属性草稿与回调是否串稿的关键输入。初始文件已保存、无未提交草稿；测试前保留两份原始文件以便复测。

## 人工连续操作（约 15–20 分钟）

| 步骤 | 操作 | 通过标准 / 回读 |
| --- | --- | --- |
| 1 | 从产品入口启动，看首页、左侧本地稿件列表和顶部入口 | 按设计对照检查范围内布局、token 和控件状态，并列出未交付的首页 Agent 入口等差异；列表来自实际文件；不出现 FigCraft 外围面板、S001 滑块 / 输入法测试控件或假稿件 |
| 2 | 新建临时空稿件，查看空页图层区，创建一个矩形，再返回首页；关闭时先选择取消，确认后再次关闭并明确丢弃这份临时稿件 | 进入空稿只见本稿页面，图层区为空；建矩形后树中出现该节点；返回首页不丢图层且不继续响应画布绘图快捷键；取消关闭后标签及矩形保留；明确丢弃后才移除该临时标签并回到首页，不影响生成的 A/B 文件 |
| 3 | 从首页打开生成的 A，再打开 B，然后再次打开 A | 标签分别指向实际 A/B；重复打开 A 复用原标签，不出现同文件副本；取消一次文件选择器不增加标签 |
| 4 | 记录 A 主矩形的描边，从图层树点选它，通过右栏确认初值；将 W 从 150 改为 180 并提交 | 选中行与画布、右栏指向同一矩形，Kodma 选框为 `#6738EF`，对象描边与选中前一致；画布、右栏及节点回读均为 180，dirty 更新；未改的 X/Y/H、填充及不透明度不变 |
| 5 | Cmd+Z，再 Shift+Cmd+Z | 一次撤销回到 W=150，一次重做回到 W=180；不是按每个输入字符撤销 |
| 6 | 在 A 平移 / 缩放、保留主矩形选区，切 B 并选中 B 主矩形，再返回 A | 左栏切为 B 的页面与图层，画布点选同步高亮 B 的节点；B 显示自己的 220×120 和 60%，不显示 A 的属性；A 恢复自己的选区、视口及 W=180；B 的撤销不能撤回 A 的修改 |
| 7 | 在 A 的 W 字段输入 999，先不提交，点击 B 标签；再在 B 点击其他控件，返回 A | A 仍为 180，B 仍为 220；未提交草稿已取消，迟到的结束编辑事件不写任何稿件；字段恢复目标的实际值 |
| 8 | 在 A 的属性字段输入非法数值并确认，再输入合法值后按 Escape；取消一次另存为 | 没有无效命令落盘、没有多出的撤销步骤；Escape 与取消另存为都保留原值、原路径和 dirty 状态；有必要的原错误反馈 |
| 9 | 在 A 选主矩形和辅助矩形，查看混合不透明度 / 颜色，只将不透明度提交为 75% | 混合状态不会自动写值；两个目标变为 75%，各自颜色、尺寸和位置不变；一次撤销恢复原来不同的不透明度 |
| 10 | 选中复杂填充及混合样式文字，再切回普通文字，修改文字内容与字号 | 未支持字段禁用，原复杂数据仍在；普通文字按本阶段属性集可改，一次确认可一次撤销；没有选区时不沿用上一图层数据 |
| 11 | 在名称 / 文字等原生字段用系统中文输入法组词、取消、替换；组词中切画布、再返回字段；执行原生 Cmd+A/C/V/Z | 无丢字、串字、重复提交或旧预编辑，候选窗跟随当前光标；原生编辑不移动 / 删除画布对象，回到画布后正常拖动和撤销 |
| 12 | 调整窗口大小和界面缩放；在左侧、顶部和右侧边缘附近选择、拖动、改属性 | 原生控件与画布区域不重叠响应；手柄、文字光标和命中对齐；没有上游侧栏意外露出。无需跨物理显示比例 |
| 13 | 先在 A 选中主矩形，再切到 B。保持 B 可见，执行交付的 attached MCP 脚本，明确修改 A 主矩形填充为 `#FF9687`；再返回 A | B 标签、选区、右栏和画布均不变；MCP 回读 A 成功，返回 A 后画布和右栏都显示珊瑚色 |
| 14 | 拖动 A 的刚变色矩形，再撤销两次；随后用 MCP 修改当前可见稿件的同一对象 | 第一次撤销仅撤回手势，第二次仅撤回 MCP 变色；前台 MCP 结果立即反映在画布与右栏，不需重新选择图层 |
| 15 | 保存 A/B；把 A 再改为 dirty，关闭 A 时分别走“取消”及“保存并关闭”；关闭最后一份稿件 | 取消保留 A；保存成功才关闭；其余标签身份不漂移；最后一份关闭回到首页，原生右栏没有旧对象残留 |
| 16 | 完全退出，重新启动，从首页重新打开保存的 A/B | 文件内容与确认保存的结果一致，可以继续编辑和使用 MCP。重启后的文档 UID 可变化，文件及节点归属必须正确；不要求新实现跨启动的撤销历史或标签布局恢复 |

首页“最近稿件”缺失文件的检查使用本次生成的可丢弃测试副本：准备入口创建其最近记录后，在验收夹具中移走该副本，再从列表打开。应出现既有失败反馈，不新增幽灵标签，不覆盖或删除其他文件；不要移动私人稿件。

## 开发侧必须补的确定性场景

| 场景 | 构造与断言 |
| --- | --- |
| 多页与层级 | 在临时稿创建两页，一页为空，另一页包含父子节点。切页检查树与画布同步；展开父节点，从树和画布分别点选子节点，核对同一选区与右栏；切空页后没有旧行或旧属性。 |
| 延迟回调与索引漂移 | 捕获 A 的属性草稿后切 B，关闭 A 或其前面的标签，再投递旧回调；不得以旧 index 或同 NodeId 修改 B。对关闭 / 再打开 A 后旧 UID 的回调同样拒绝 |
| 外部变更冲突 | 草稿捕获的字段在提交前被 MCP 改写，或目标节点被删除；旧草稿失效，显示最新值或清空，不静默覆盖，不提交到其他节点 |
| 多选及不适用属性 | 混合值、空选区、复杂填充与混合文字样式的字段启用状态正确；仅明确修改的字段改变，批次失败按原引擎事务语义回滚 |
| 只读路径 | 使用已有只读文件 / 会话能力构造目标；原生字段不可写，实际命令绕过 UI 禁用后也被原引擎拒绝。拒绝不污染历史或其他稿件 |
| 首页 / 隐藏后的后台修改 | 保持首页或最小化应用，MCP 明确修改 A；回读成功，恢复 A 后为最新值，首页和 B 不被改成 A 的界面 |
| 撤销与焦点 | 属性一次确认、画布一次手势及 MCP 一次命令分别成事务；键盘归属覆盖多个字段、输入源切换、系统对话框和画布 |
| 生命周期与资源 | 重复首页 / A/B 切换、打开 / 关闭和正常退出；核对控件与订阅不重复、旧结果不覆盖、新增轮询或布局重建的短程 CPU / 内存开销，与 S001 对照 |
| 原入口与升级 | 默认 FigCraft、S001 控制 / MCP / 输入路径及适用 WASM 检查；在明确上游提交上复跑首页→A/B→右栏→MCP→保存重开，记录实际差异 |

另外回读测试对象原有圆角、描边、效果，以及多页稿件状态：切稿、修改其他字段、保存重开后，原值与页面归属应保持一致。

这些场景使用测试夹具或受限测试钩子构造，不新增能够绕过权限或草稿校验的生产命令。机器回归、真实原生操作、系统输入法、性能测量和上游演练各自记录证据。
