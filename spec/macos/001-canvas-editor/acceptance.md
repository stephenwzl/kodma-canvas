# S001 亲自验收：编辑一张卡片，保存后重新打开

预计 10–15 分钟。验收对象是保留完整 FigCraft 运行时的 macOS 验证宿主；右侧输入框、滑块和输入源下拉框是测试控件。本用例不是 Kodma 产品工作区的验收。

2026-11-16 用户确认 S001 验收通过，已按 [spec](spec.md) 关闭。本用例保留供后续回归，开发检查与用户验收结论见[进度](progress.md)。

## 启动与测试稿

在仓库根目录运行：

```sh
./script/accept_s001.sh
```

会构建并打开验证应用，生成并显示一份新的「S001 验收卡片」。准备完成时终端打印 `.figcraft` 文件路径；文件保存在 `dist/s001-acceptance/`，每次使用新文件名，保留之前的验收修改。已经构建过时可以加 `--no-build`。

测试稿包含：锁定的白色底卡、中文标题、蓝色矩形、珊瑚色圆形、薄荷绿矩形、按钮文字和程序生成的棋盘格图片。内容来自[合成命令](fixtures/card.json)和[生成脚本](../../../script/prepare_s001.rb)，不含第三方设计稿、图标或图片。`latest.json` 记录本次文件及对象 ID，供同一稿件的 MCP 验证使用。

脚本只重启 KodmaCanvas 验证进程。若其中有需要保留的编辑，先保存。首次构建和系统字体扫描不计入交互耗时。

## 连续操作 case

| 步骤 | 亲自操作 | 通过标准 |
| --- | --- | --- |
| 1 | 查看窗口；点击各图形 | 没有 FigCraft 首页、标签条、工具栏和两侧属性面板；选区和编辑手柄正常显示 |
| 2 | 拖动蓝色矩形；Cmd+Z，再 Shift+Cmd+Z | 完整跟随鼠标；一次撤销回到起点，一次重做回到终点 |
| 3 | 按住 Shift 点击蓝色矩形和圆形；从矩形内部靠近边缘的位置拖动 | 两个对象一起移动。避开对象中心的智能选区重排圆点，以免触发重排 |
| 4 | 点击画布空白处，从图形左上方空白拖一个框，把三个彩色图形圈住 | 选中三个图形；白色底卡已锁定，不随它们移动 |
| 5 | 单选蓝色矩形，拖动右下角尺寸手柄；撤销后，从角点稍外侧拖动旋转 | 尺寸及旋转实时更新；各自一次撤销恢复。角点本身调整尺寸，角外旋转 |
| 6 | 先点右侧原生输入框，使输入源下拉框可用，选择已启用的中文输入源并确认处于中文模式；再双击标题，Cmd+A，逐键输入 `shijie` 并空格 | 标题变成“世界”；**亲自看候选窗是否紧跟正在输入的光标**，不是固定在窗口角落或屏幕另一处 |
| 7 | 标题末尾输入 `ni`，按 Escape；再输入 `ni`，不提交就点击右侧原生输入框 | 取消后标题仍为“世界”；转移焦点后旧预编辑消失，不残留 `ni` 或把字提交到另一处 |
| 8 | 原生输入框逐键输入 `nihao` 并空格；Cmd+A 后输入 `zhongwen` 并空格；再返回标题输入 `nihao` 并空格 | 原生框为“中文”，标题为“世界你好”；无丢字、重复字或串字。原生框的 Cmd+A / C / X / V / Z 正常，画布内容不受影响 |
| 9 | 回到画布，选中图形 Cmd+C、Cmd+V，把新副本拖开；Cmd+Z | 能看到新增副本；画布撤销使用画布历史，不误撤销原生输入框。原生 Edit 菜单在原生字段编辑时可用，回到画布后退出 |
| 10 | 拖右侧滑块改变原生区域宽度，调整窗口大小和位置，再拖动图形与编辑标题 | 图形、手柄、文本光标和鼠标命中对齐；没有残影、裁切或上游外围 UI 意外出现 |
| 11 | 已取消：跨不同缩放比例显示器测试，不作为 S001 验收要求 | 按用户决定取消，不计为已测试通过 |
| 12 | 在画布上拖入一张自己的合成图片或 SVG；打开文件选择器后取消，再继续拖动已有图形 | 导入出现在收到拖放的稿件中；取消选择器不修改稿件或破坏编辑状态。可用下方命令生成的 `drop.svg`，无需私人文件 |
| 13 | 执行下面的 attached MCP 修改；回到画布拖动刚变色的矩形，再撤销两次 | 蓝色矩形经真实 MCP 变成珊瑚色；第一次撤销撤回鼠标移动，第二次撤销撤回 MCP 变色，互不合并 |
| 14 | Cmd+S 保存；Cmd+O 选择终端打印的本次文件路径；完全退出后，用该文件再次启动 | 标题、图形、颜色和图片保留，能继续编辑；重新打开仍是仅画布宿主 |

MCP 操作在同一仓库根目录执行；运行前保持本次生成的卡片在前台：

```sh
ruby script/s001_agent_edit.rb 17981
```

生成拖放用的合成 SVG（也可以使用自己创建的合成文件）：

```sh
ruby -e 'File.write("dist/s001-acceptance/drop.svg", %q{<svg xmlns="http://www.w3.org/2000/svg" width="120" height="80"><rect width="120" height="80" rx="12" fill="#99d9bd"/></svg>})'
```

从 Finder 拖该文件进画布。直接执行 `file.import` 或注入原始文件事件不能替代这一系统拖放观察。

重新启动并打开保存文件：

```sh
./script/build_and_run.sh --no-build --verify --control 17981 <本次文件路径>
```

需要对照时，使用同一个文件启动默认编辑器：

```sh
./script/build_and_run.sh --reference --no-build --verify --control 17982 <本次文件路径>
```

## 后台补充检查

先保存卡片并用 Cmd+H 隐藏应用，再在仓库根目录运行：

```sh
ruby script/verify_canvas_host.rb 17981 --background
```

此脚本新建另一份合成稿件并通过控制通道和 attached MCP 编辑；不会修改卡片。完成后从 Dock 或 Finder 打开 KodmaCanvas 恢复应用，应该显示最新的合成验证对象。若要继续卡片 case，重新运行准备入口或打开之前的卡片文件。
