## 开发与验收如何使用

I1 先把本表转换为实施清单：每个范围内控件对应设计节点、真实数据源、原命令、启用状态、布局及必要差异。对缺少设计状态的多选、错误、无选区和新增字段，采用现有控件规范并记录，不能靠一张静态成功截图补齐。

AC01 的视觉对照只判定本阶段纳入的部分，并附上完整缺项表；缺项仍是未交付，不能把功能子集标成“四页高保真还原”。如要把上述缺项纳入 S002，应先修订范围、实施顺序和验收，不在开发中自行添加 Agent 后端或模拟结果。最终 UI 验收必须观察原生宿主实际截图，设计稿渲染仅证明设计来源。
