# Kodma 实施规格

| 平台 | 当前规格 | 下一步 |
| --- | --- | --- |
| [Web](web/README.md) | S004：浏览器工作区与 Cloudflare 云端稿件 | 用户确认 v1.1 架构图与规格后进入 I1 |
