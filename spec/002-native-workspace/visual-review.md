- 保留同一个 NSWindow、WinitView、完整 FigApp / Session 与原有画布。内容尺寸 1440 × 960，左栏 242、顶栏 84、右栏 408；隐藏额外系统标题栏，与设计基准对齐。
- 首页还原原创字标、插画、66 / 68 字号标题、920 × 172 圆角输入区、底部三个彩色入口、导航与顶部标签。最近稿件始终来自实际本地文件。
- 编辑态补齐稿件 / 页面分层、选中稿件底色、分隔线、底部账户区域、原生标签、新建与保存图标，以及 508 × 52 悬浮工具条。工具条经原命令运行，不建立另一套工具状态。

- I4 截图记录的是旧版稿件侧栏和蓝色选框（`#5065CC`）。v1.2 需重新截取空稿、已有图层的编辑态，并核对紫色 `#6738EF` 选框；默认 FigCraft 与 S001 宿主保留原有配色。原生控件图标在代码中从简单几何原创绘制。两项原创设计资产单独导出并登记于 `ATTRIBUTION.md`，未把整张界面截图用作应用背景。

## 明示差异与后续

- Agent 服务、账户、设置、分享尚未接入，入口采用禁用状态；不展示虚构协作者或登录头像。当前页面名称为只读观察，尚未提供完整原生多页切换。
- 原生英文字体使用系统字体，不复制字体文件；字宽及控件禁用颜色与设计字体存在差异。原生文件打开 / 保存入口保留，使用小图标呈现。
- 画布使用真实缩放值（此测试稿为 100%，设计示意写 75%）与实际图层名、选择手柄、圆角手柄和尺寸提示；不以假数值或装饰性选区替代编辑器。
- 本轮只完成界面所需构建、场景准备与视觉检查，**未执行功能验收或完整 CI**。一次右栏滚动观察到画布视口变化，原因未确认，功能阶段优先核对原生事件与画布的隔离；不据截图宣称输入 / 焦点已通过。
- UI 视觉验收后，继续 AC05–AC07 的属性事务、失效草稿、焦点保障，再进入 I5；系统中文输入法由用户亲自验收，沿用已确认安排。
