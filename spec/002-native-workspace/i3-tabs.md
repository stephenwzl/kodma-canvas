# S002 I3：稿件标签、关闭与状态隔离

更新日期：2026-11-17。状态：**I3 已完成，S002 经用户整体验收通过并关闭**。以下保留 I3 当轮实现与回归步骤；后续 I4–I5 也已结项，最新结论见[迭代进度](progress.md)。

## 实现

顶部原生标签从原 `Session.docs` 的当前窗口投影读取 UID、真实名称与 dirty；前导实心点标识当前稿件，名称后的点标识未保存。首页不标记任何稿件为当前，但保留打开标签。标签内容横向滚动，左右按钮直接滚动；名称和 dirty 更新不重建整条标签，窗口尺寸变化才更新滚动容器尺寸，避免稳定刷新重置用户滚动。长名称截短显示，提示保留原名称。

Switch / Close 意图捕获 UID，执行前重新确认所属窗口并查找当前索引；关闭前一项后的迟到事件不会命中下一项。同一文件仍由原 `file.openRecent/open` 复用已打开文档。选区、页面、视口、撤销 / 重做继续归原 DocState，原生层不保存这些状态副本。

关闭走原 `ask_close_tab` / `TabClose` 状态机。其 Ask 阶段由附着原窗口的异步系统弹窗呈现保存 / 不保存 / 取消；回答携带 UID，仍交给原 `answer_close_tab`，不把原 egui 问题重复画在原生首页后面。关闭确认与系统文件选择器期间禁用导航并拒绝迟到操作；`ui.workspace` 的 `busy` 包含整个关闭流程，`close_question` 只观察当前 Ask 的 UID。该接口只读，不添加强制丢弃或回答对话框的程序化端点。

保存 / 另存为按钮捕获当前稿件 UID，目标已切换、离开当前窗口或已回首页时拒绝旧事件，使用原保存和异步文件选择器。取消或失败不清 dirty、不关稿件。关闭后台稿件时，原状态机曾在保存失败后留在该稿件；本轮回归先复现失败，再修正为保存或启动绑定原 UID 的另存为后恢复之前的前台稿件。成功关闭、失败及取消都不把另一份稿件切走。

保留完整 Session / FigApp / UiState、帧循环、后台调度、控制、MCP、NSWindow / WinitView 所有权；没有新增依赖版本、资产、unsafe 或共享 CI 变更。窗口退出前沿用 Host 清理。独立窗口产品化仍不在本轮范围，外窗 UID 拒绝测试不等于完整多窗口 UI 验收。

## 启动与测试稿

在仓库根目录执行：

```bash
./script/accept_s002_i3.sh
```

脚本使用独立配置与唯一生成目录，准备真实 `.figcraft` 最近记录，不加载个人文件。`dist/s002-i3/latest.json` 保存 A/B 路径、相同的主矩形 NodeId、端口和配置目录；每份 `.original` 是此次合成文件的原始备份。脚本只准备夹具，不自动宣布人工验收通过。

A：蓝色矩形 `(120,200,150,100)`、普通文字“你好，Kodma A” / 32；B：薄荷绿矩形 `(360,200,220,120)`、60% 不透明度、文字“你好，Kodma B” / 24；均有辅助矩形。初始保存且无 dirty。主矩形 NodeId 均为 2，所属文件不同。I3 夹具覆盖切稿与文件操作；完整 case 的渐变 / 混合文字样式等属性夹具随 I4 提供，不记为已验证。若系统没有稿件指定字体，关闭 FigCraft 的缺字提示即可继续，保留原有字体回退行为，不需要下载字体。

## 亲自验收（约 8 分钟）

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 从最近记录打开 A、B，再打开 A | 两个真实标签，重复打开复用；A/B 的蓝色 / 绿色和名称对应，当前标识正确 |
| 2 | 在 A 选中并拖动蓝矩形，切到 B 选中绿矩形，再切回 A | A 的位置、选区保留；B 的内容和选区独立；dirty 只反映被修改的稿件 |
| 3 | 返回首页，再点 A 标签 | 首页保留两稿；返回 A 恢复原画布，右栏只读摘要对应当前选区。可编辑属性在 I4 |
| 4 | 点 A 的 ×，先取消 | 原稿及修改保留；取消后可以继续切稿和编辑 |
| 5 | 切 B 前台，点后台 A 的 ×，选择保存 | 保存 A 后只关闭 A；B 保持前台，选区、视口不丢。通过最近记录重开 A，拖动内容仍在 |
| 6 | 在 A 点另存为，先取消；再另存为一个新的合成副本名称 | 取消不改变原稿；成功后标签名称 / 路径更新，保存按钮可保存后续修改 |
| 7 | 新建临时稿并画一个矩形；关闭 → 保存 → 在选择器取消；再关闭 → 不保存 | 首次仍保留脏稿；明确不保存后只移除临时稿。可以用原控制 / MCP 创建矩形；测试稿均为合成内容 |
| 8 | 保存 A/B 后关闭所有标签 | 最后一份关闭后回首页，右栏不留旧选区；正常退出并重开保存文件仍可继续编辑 |

可选：多新建几份空稿，使用标签区左右按钮到达首尾，切换并关闭任意标签；调整窗口和界面缩放，标签、按钮和画布命中应保持对应。原撤销 / 重做仍属于当前稿件；本轮通过原命令路径核验了 A/B 历史隔离，不把此前未生效的自动化 Cmd+Z 注入记为已修复。
