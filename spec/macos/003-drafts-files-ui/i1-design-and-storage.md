## 存储与命令实施方案

- 应用管理目录由 Desktop 平台服务解析，沿用可隔离的配置根，在其下设 Drafts/<稳定随机标识>.figcraft。不使用显示名称或运行时 UID 作为文件标识。索引只存标识、名称、定位与排序元信息；打开时由 Session 重新绑定 UID。
- 所有用户可见动作注册命令，原生宿主只发送目标身份和意图。文件与索引 I/O 留在平台 / 持久层，底层命令不依赖 AppKit；非原生和 WASM 保持原行为。具体命令 ID 在实现时注册并测试。
- 创建：file.new 后先赋产品默认名（避免 save_to 因 Untitled 而把 UUID 文件 stem 当显示名），再复用 file.save 的格式和原子写入；成功后发布索引记录。索引写失败时保留已落盘文件，下一次扫描可恢复登记；未写成功不发布列表项。目录扫描有界、分批，不在 UI 帧内逐一解码全部文件。
- 列表：索引合并已登记外部路径，规范化路径去重，以稳定身份执行排序 / 搜索 / 延迟回调。保留失效条目供移除，不自动打开成空稿。不按名称去重；同名用菜单 / tooltip 中路径辨认，不常驻二级标签。旧 recent 只登记外部引用，幂等处理，不搬文件。
- 命名：验证去首尾空白后非空；Enter 提交，Escape 放弃。file.rename 后写入同一内容文件，再更新索引名称。写失败保留 dirty 与内存名，列表可从打开文档显示当前名；失败不能记录为已持久保存。
- 另存为：先将应用内原稿保存成功，再调用原 file.saveAs / picker。save_to 在目标写入成功后才更换当前标签路径，原稿保留；仅此时把运行时绑定转为外部文件，原应用内索引继续定位旧文件。取消 / 失败保留原绑定。重新打开原稿取得独立 UID。不在磁盘副本成功前更新列表。
- 关闭、回首页与退出：应用内稿件先完成保存，异步期间锁定目标身份；失败显示可取消 / 重试的错误。未完成写入不能清 dirty 或关闭目标。外部文件继续既有未保存确认。

## 保存机制核对

| 现有机制 | 定义与实际规则 | S003 使用 |
| --- | --- | --- |
| 主文件自动保存 | ui-egui/src/app/files.rs 的 auto_save_tick；clock.rs 为静止 3 秒，失败重试 60 秒；Prefs 默认 auto_save=false。需有 path、dirty、非分支 / 预览，交互进行时延后；后台逻辑也调用 | 应用内稿件必须自动保存，不修改全局偏好来连带改变外部文件；在既有 due 筛选中纳入受管稿件 |
| 快照写回 | engine/src/cmd/file/save.rs 的 FileSnapshot::save 校验 UID、路径及 saved_doc；新编辑仍 dirty，旧回调不得写向新目标 | 复用并覆盖另存为 / 关闭 / 删除竞态，不另造文档副本 |
| 主文件写入 | file/load.rs 复用 format::write_file_atomic；自动保存检查磁盘变化，避免覆盖外部修改 | 失败保留 dirty，显式冲突交用户选择，不强制 overwrite |
| 版本检查点 | autosave_tick 每 30 分钟执行 version.autosave | 保留，不能作为主文件保存成功证据 |
| 恢复副本 | apps/figcraft/src/recovery.rs：持续修改期间最多每 10 秒保存恢复副本 | 保留崩溃保护，不能作为创建完成或正常重启目录 |

保存中保留 dirty；成功以对应快照写回结果为准；失败显示必要错误和重试，标签已有 dirty 语义继续使用。避免新增常驻保存状态说明。外部文件不被强制开启自动保存。

## 废纸篓与移除

已打开 objc2-foundation 0.3.2 的 NSFileManager 定义，trashItemAtURL_resultingItemURL_error 是可安全调用的 Result 接口，受 NSError / NSURL / NSFileManager feature 控制。当前 apps/figcraft/Cargo.toml 未显式开启这些 feature；实现时只启用已有依赖相应功能，不增加依赖或 unsafe，不调用永久删除兜底。

应用内目标先保存、确认后平台移到系统废纸篓；成功后才关目标标签 / 移除索引，失败保持原状态。异步保存须先排空或作废，防止成功删除后旧写回重建原文件。索引移除失败可在刷新时识别缺失文件并保留可移除错误项，不谎报文件仍在原处。外部文件只移除登记，已打开标签仍可编辑；显式重新打开可登记。恢复从系统废纸篓通过“打开稿件”验证，本期不建应用回收站。实际平台操作与取消 / 失败尚未执行。
