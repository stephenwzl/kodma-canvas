# I4：固定设计右栏与亲验 case

日期：2026-11-16。用户决定沿用当前整窗 UI，I4 工程开发与本轮功能验收完成；系统中文输入法由用户亲验，AC07 尚未整体关闭。S002 仍需 I5 完整闭环和升级回归。

## 实现边界

保留完整 FigApp / Session / UiState、原 NSWindow / WinitView、帧循环、控制通道及 attached MCP。原生右栏只是选区投影与短暂字段草稿，提交仍经原 `node.set` / `fill.set` 命令和事务历史，无第二套文档、撤销或协作状态。

- 单选开放名称、X/Y、W/H、旋转、透明度、简单纯色，以及适用的文字内容 / 字号。多选仅开放共同透明度和适用的单项纯色，混合值不会自动落盘。
- 非法数值、锁定 / 只读目标拒绝提交；渐变、多项填充、绑定和复杂文字样式不被简化。正常 RGBA 颜色改变 RGB 时保留 paint opacity / color_alpha；未规范化的原始颜色 alpha 不通过 RGB 字段覆盖。
- 草稿捕获运行时 UID、页、选区和观察代次。实际文档 Arc 的 Weak 身份用于识别写入，不使用查询也会递增的 repaint revision；切稿、换选区、关闭、外部写入 / 删除及只读状态变化取消旧草稿。同 NodeId 不允许跨文件提交。
- Return / Tab 确认、Escape 取消；首页 / 标签 / 关闭优先取消旧草稿。外部失效后的迟到 Return / Delete 留在窗口，不传给画布；用户再次点击画布后恢复原编辑。
- 原生编辑菜单通过既有 craft-menu 按 AppKit 实际 first responder 同步分发。字段内 Cmd+A/C/V/Z 属于原生文本，画布命令携带发起稿件 UID；Quit 仍走原未保存确认。
- 右栏标题的透明命中范围收窄，圆角标签不再挡住透明度；图标按钮增加与外观一致的完整命中区域。圆角、描边和效果仍只读，Agent / 账户 / 分享保持未接入状态。

## 准备测试稿

在仓库根目录运行：

```sh
./script/accept_s002_i4.sh
```

使用隔离配置启动工作区、生成独立 A/B 文件并返回首页。已构建同一版本时可用 `--no-build`。每次创建新的 run 目录，不覆盖之前稿件；脚本只准备夹具，不能据此声称人工验收通过。

`dist/s002-i4/latest.json` 记录本轮文件路径与节点 ID；`.original` 保留初始内容。A/B 的主矩形均为 NodeId 2，但宽分别为 150 / 220，颜色为蓝 / 绿。节点 3 是文字、4 是辅助矩形；A 另有渐变 5、混合文字样式 6。实际截图在本地忽略目录 `dist/s002-i4/ready-for-user.jpg`，不作为应用资产提交。

## 亲自验收（约 5 分钟）

1. 从首页打开 A，再打开 B，返回 A。点击蓝色矩形，右栏应为 W150、H100、透明度100%；切 B 时应为 W220、H120、透明度60%。
2. 在 A 将 W 改为180后 Return，再将 H 改为120后 Return。每次确认画布更新；画布 Cmd+Z 两次应分别恢复 H100、W150。重做两次回180×120。
3. 输入 W999，按 Escape，仍为180。再输入 W999，不确认直接切 B；B 仍为220，返回 A 仍为180。关闭 A 再从最近记录重开，未提交的999不能保存。
4. 改透明度75%、填充 `#112233`，分别确认，再分别撤销。多选主矩形与辅助矩形，只改透明度75%，一次撤销恢复各自100% / 50%，颜色不变。
5. 点选文字，滚动右栏到“更多属性”：改字号24、文字内容、旋转15，逐项确认并逐项撤销。选渐变时 RGB 字段不可覆盖渐变；选混合文字时不能将原样式抹平。
6. 字段内 Cmd+A/C/V/Z 应只编辑草稿，画布内容在提交前不变；回到画布后 Cmd+Z 撤销原文档修改。打开系统文件选择器后取消，等待返回工作区，仍可编辑原稿。Cmd+Q 有未保存确认时按取消，继续保留稿件。
7. **中文由用户亲验：**系统切至拼音，在名称或文字字段组词并选词，观察候选窗是否跟随当前字段；确认、取消预编辑、替换已有文字；在两个字段、画布和 A/B 标签间切换。预期无串字、丢字、重复提交或旧预编辑；字段内退格 / 全选 / 粘贴 / 撤销不修改画布。此项尚未由工程自动化代替验收。

验证宿主空闲约100 ms轮询、字段编辑期间约16 ms。Tab 后新字段在消费确认键之前建立草稿，避免快速首次 Return 被漏掉；系统输入法由用户亲验。跨物理显示比例按用户决定排除。

## 工程验收证据

实际原生窗口检查了属性提交、Tab / Escape、原生编辑快捷键、真实鼠标拖动 / 撤销、切稿关闭 / 重开、目标删除 / 外部修改后的迟到按键、退出确认和系统打开取消。最后构建还回读确认了查询期间继续提交、W/H、75%透明度及文字24号 / 内容 / 15度旋转。

三个新增回归在旧行为上先失败：标题遮挡输入命中、未规范化颜色 alpha 被 RGB 提交覆盖、只读查询错误取消草稿。其余目标 / 混合值 / 历史隔离及 IME 按键门控由定向测试覆盖；测试门控不等于系统中文输入法已通过。准确测试数量与 CI 基线见[进度](progress.md)。
