# S002 I2：首页与本地文件

更新日期：2026-11-17。状态：**I2 已完成，S002 经用户整体验收通过并关闭**。以下保留 I2 当轮实现与回归步骤；后续 I3–I5 也已结项，最新结论见[迭代进度](progress.md)。

## 实现与边界

原生首页接通新建、系统文件选择器、真实最近记录及返回首页。仍使用同一 Session / FigApp / UiState、后台 tick、帧循环、控制、MCP、历史及保存路径；不拆分或替换 FigCraft 运行时，也不替换 NSWindow / WinitView。

`workspace_action` 是宿主 UI 意图接口，New / Open / Home / Recent 分别走原文件命令、异步选择器及首页请求；程序化控制和 MCP 不通过它打开对话框。选择器期间以原 `pending_dialog` 投影的 `busy` 禁用导航并拒绝迟到导航，避免替换未结束的操作。控件在主线程轮询消费一次点击，复用既有原生编辑菜单；窗口失去 key 状态时不把键盘交给画布。

最近记录来自原 prefs 与既有文件访问过滤，最多 20 条，使用实际完整路径作为回调目标；提交前重新检查该记录仍存在，重排不按旧索引打开。记录变化时重建列表，稳定 tick 不全量重建、不反复读取文件 metadata。列表可滚动；名称仅截短显示，提示保留完整路径。路径不进入公开 `ui.workspace` 快照。

错误显示原始命令结果并换行，下一次有效操作清除旧提示。缺失文件按原语义移除对应最近记录，损坏文件不生成文档；取消或失败保留原文档、dirty 和历史。没有另建错误恢复或文档模型。

本轮是 AC01 首页 / 文件入口子集及 AC02，不代表完整高保真、全部 AC01 或 S002 已完成。字标、插画、完整组件样式继续见[差异清单](implementation.md)和[设计范围](design-reference.md)；完整可点击稿件标签 / 关闭在 I3，编辑属性 / 中文 / 焦点矩阵在 I4。产品 UI 只增加操作控件及必要错误反馈，没有增加二级说明文案。

## 一键准备与亲验

在仓库根目录运行：

```bash
./script/accept_s002_i2.sh
```

脚本构建启动原生工作区，在独立配置目录生成三份合成稿件及真实最近记录；不会载入个人最近文件。`dist/s002-i2/latest.json` 保存本轮路径、控制端口与配置目录。蓝色稿件有一个可拖动矩形；缺失稿件只移动此次生成文件到 `.backup`，损坏稿件先保留此次生成文件的 `.backup` 再写入无效内容。每次新建独立 run 目录；脚本完成表示夹具准备完成，不表示以下人工步骤自动通过。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 首页点击新建，再点击顶部首页 | 新建真实空文档；返回首页保留该文档。完整稿件标签待 I3 |
| 2 | 点击「I2 蓝色卡片」最近项 | 进入蓝色矩形稿件，可以实际选中和拖动 |
| 3 | 拖动矩形，点击首页 → 打开稿件 → 取消 | 保持首页，原蓝色稿件及修改仍保留；再次点蓝色最近项能恢复修改，dirty 仍在 |
| 4 | 返回首页，点「I2 已移走稿件」 | 出现原始错误，仅该最近记录被移除；不破坏蓝色稿件、不产生空文档 |
| 5 | 点「I2 损坏稿件」；再用打开选择器选择同一损坏文件 | 均显示解析错误；蓝色稿件和未保存修改保留，不产生幽灵文档 |
| 6 | 再点蓝色最近项 | 正确复用已打开文档，旧错误清除 |
| 7 | 首页 → 打开稿件，在系统选择器选 `latest.json` 中的 actual 文件 | 打开真实文件；已打开时复用原稿件，未保存修改仍保留 |

不要把新建空稿件的完整标签导航当成本轮交付。重复启动准备脚本会使用新的隔离配置；验证最近记录持久化须正常退出后，用 manifest 的同一 config 作为 `KODMA_CANVAS_CONFIG_DIR` 再执行 `./script/build_and_run.sh --workspace --no-build --verify --control 17982`。

## 实际证据与限制

原生实机已点击新建、返回首页、最近项、系统打开 / 取消 / 选中文件；验证缺失与损坏错误、重复打开 UID 复用、真实鼠标拖动后取消 / 失败保留 dirty。另生成 20 条真实记录，实际滚动到末项并打开正确完整路径。截图均已人工读取，未提交截图或外部资产。正常退出重启同一独立配置后，三条真实最近记录仍在、文档列表为空。不同 case 使用独立生成 run，不能把跨进程相同 UID 当成同一文档身份。

原控制命令 `edit.undo` 恢复矩形位置并成功保存；这不等于物理 Cmd+Z 验收通过。自动化注入 Cmd+A / V（系统路径框）及 Cmd+Z（画布）未生效；默认 FigCraft 入口的系统路径框也复现 Cmd+A 后未全选的现象。系统菜单点击 Select All 可用；该探测尚不能确认实际应用根因，也不记为已修复。AC07 未通过，随 I4 的系统中文、焦点及快捷键实机矩阵继续验收。
